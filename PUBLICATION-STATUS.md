# Distribution

Project home: [andrem000/prospect-review](https://github.com/andrem000/prospect-review).

Run the local app from a source checkout with `python -m prospect app`, or run the reproducible CLI demo with `python demo.py`. Install with `python -m pip install .` to use `prospect-review app` outside the checkout. The distribution name is `prospect-review`, the import/module name is `prospect`, and both `prospect-review` and `prospect` are console commands.

GitHub tags and releases identify published versions. Installation instructions use this source repository and do not require a PyPI publication.
