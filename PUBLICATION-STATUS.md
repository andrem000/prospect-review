# Distribution

Project home: [andrem000/prospect-review](https://github.com/andrem000/prospect-review).

The public project starts at **v0.1.0**. Install from a source checkout with `python -m pip install .`, or run `python demo.py` without installation. The distribution name is `prospect-review`, the import/module name is `prospect`, and both `prospect-review` and `prospect` are console commands.

GitHub tags and releases identify published versions. Installation instructions use this source repository and do not require a PyPI publication.
